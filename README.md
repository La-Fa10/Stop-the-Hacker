Stop the Hacker

About
An interactive cybersecurity awareness game designed to teach users how to protect their devices and personal information from cyber threats through four scenarios: Wi-Fi security, password and two-factor authentication (2FA), phishing detection, and payment safety.

Features
Learn how to use Wi-Fi networks safely.
Understand password security and two-factor authentication (2FA).
Identify phishing messages and suspicious links.
Learn safe online payment practices.
