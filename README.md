# Stop the Hacker

An interactive cybersecurity awareness game designed to teach users how to stay safe online through four scenarios: Wi-Fi security, password and two-factor authentication (2FA), phishing detection, and payment safety.

## Project Objectives

* Raise awareness about cybersecurity.
* Encourage safe online behavior.
* Help users recognize common cyber threats.
